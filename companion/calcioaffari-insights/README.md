# CalcioAffari Insights 1.0.0

Plugin proprietario per:

- statistiche orarie e giornaliere aggregate, senza cookie o identificatori personali;
- trend nel backend WordPress;
- alert email solo quando le fonti vengono raccolte ma l'agente locale non risponde;
- persistenza della squadra preferita per gli utenti autenticati;
- creazione della Cookie Policy coerente con gli strumenti effettivamente attivi.
