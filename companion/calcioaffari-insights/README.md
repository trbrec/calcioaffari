# CalcioAffari Insights 1.1.1

Plugin proprietario per:

- statistiche orarie, giornaliere e settimanali aggregate, con trend e ripartizione per area;
- trend nel backend WordPress;
- alert email solo quando le fonti vengono raccolte ma l'agente locale non risponde;
- persistenza della squadra preferita per gli utenti autenticati;
- creazione della Cookie Policy coerente con gli strumenti effettivamente attivi.
- account email/password, recupero password e consensi privacy/marketing separati;
- predisposizione login Google e Facebook tramite costanti sicure in `wp-config.php`.
